Why ClearChat

  • Smart filter: catches sh1t and s h i t without joining normal words together, so "this hit" is left alone.
  • Anti-spam: message cooldown, duplicate block, caps limit and link/IP blocking with a whitelist.
  • Plays nicely: it only changes message text, so format plugins such as ClearTags keep working.

Features

  • Censor with *** or block the message
  • Caps over a set percentage made lower case (or blocked)
  • Link and IP blocking with a domain whitelist
  • @mentions highlight the name and play a sound to that player
  • /chat clear, /chat mute (global) and /chat reload
  • Bypass permissions for each check (ops have them by default)
  • Optional chat format, off by default and skipped when ClearTags is installed

Tested

Tested on Paper 1.21.4 with an op bot and a non-op bot, with ClearTags installed: leetspeak and spaced-out words were censored while normal text went through, the cooldown and duplicate block worked, all-caps was made lower case, links and IPs were blocked while a whitelisted link went through, mentions highlighted the name with a sound, /chat mute and /chat clear worked, the op bypassed the checks, and ClearTags' format still applied. Block mode for the filter and caps, and ClearChat's own optional chat format, were not bot-tested.

Example config

# ClearChat. All text is MiniMessage. Ops bypass everything by default (see plugin.yml permissions).
prefix: "<dark_gray>[<gold>Chat</gold>]</dark_gray> "
filter:
  enabled: true
  # censor = replace the word with *, block = stop the whole message.
  mode: censor
  censor-char: "*"
  # Match through leetspeak (sh1t, $hit) and spacing/punctuation (s h i t, s.h.i.t).
  normalise: true
  words: [fuck, shit, bitch, cunt, bastard, dick, wanker, twat]
  blocked-message: "<red>Please keep chat friendly."
anti-spam:
  # Seconds between messages (0 = off).
  cooldown: 2
  cooldown-message: "<red>Slow down! Wait <time>s before chatting again."
  # Block sending the same message again within this many seconds (0 = off).
  duplicate-seconds: 30
  duplicate-message: "<red>Please don't repeat the same message."
caps:
  enabled: true
  # Only check messages with at least this many letters.
  min-letters: 6
  # Max percentage of capital letters.
  max-percent: 60
  # lower = make the message lower case, block = stop it.
  mode: lower
  blocked-message: "<red>Please don't use so many capitals."
links:
  enabled: true
  block-ips: true
  # Domains that are always allowed (and their subdomains).
  whitelist: [youtube.com, discord.gg]
  blocked-message: "<red>Links aren't allowed in chat."
mentions:
  enabled: true
  # Highlight a player's name (with or without @) in chat.
  highlight: "<yellow>@<name></yellow>"
  # Sound played to the mentioned player (any Minecraft sound key). Leave empty for none.
  sound: "entity.experience_orb.pickup"
  volume: 1.0
  pitch: 1.0
# Chat format. Off by default so it never fights other chat plugins such as ClearTags.
format:
  enabled: false
  # Even when enabled, do nothing if ClearTags is installed.
  skip-if-cleartags: true
  text: "<gray><name></gray><dark_gray> » </dark_gray><white><message>"
messages:
  muted: "<red>Chat is muted right now."
  mute-on: "<red>Chat has been muted by <player>."
  mute-off: "<green>Chat has been unmuted by <player>."
  cleared: "<gray>Chat was cleared by <player>."
  reloaded: "<green>ClearChat reloaded."

Installation

Full walkthrough: ClearChat setup guide.

  1. Stop your server.
  2. Put ClearChat-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearChat/config.yml is created.
  4. Edit filter words, cooldown, caps limit, link whitelist and mention sound in the config, then run /chat reload.
