Why ClearAFK

  • Hard to fool: only head turns, chat, commands, interacting and breaking or placing blocks count as activity. Being pushed by water, pistons or vehicles doesn't.
  • Visible: an [AFK] tag shows in the tab list.
  • Fair kicks: a warning in the last 30 seconds, and an option to kick only when the server is full.

Features

  • Automatic AFK after a set time (default 5 minutes)
  • /afk to set yourself AFK by hand
  • Tab-list tag format you can change
  • Broadcast when players go AFK and come back (can be turned off)
  • Optional kick after a set time AFK
  • /afk list and /afk check <player> to see who's idle and for how long
  • MiniMessage colours in all messages
  • Tab completion

Example config

# ClearAFK - AFK detection that's hard to fool.
# Only "real" activity resets the timer: turning your head, chatting, running commands,
# interacting or breaking/placing blocks. Being pushed by water or pistons, or riding
# an AFK-pool, does not count as activity.
afk-after: 300            # seconds without activity before a player is marked AFK
kick:
  enabled: true
  after: 900              # seconds AFK (after being marked AFK) before kicking. Players with clearafk.bypass.kick are never kicked
  only-when-full: false   # only kick AFK players when the server is at max players
  message: "<red>You were kicked for being AFK too long."
announce: true            # broadcast when players go AFK / come back
tab-tag:
  enabled: true
  format: "<gray>[AFK] </gray><name>"
messages:
  prefix: "<gray>[AFK]</gray> "
  now-afk: "<gray><name> is now AFK."
  no-longer-afk: "<gray><name> is no longer AFK."
  you-afk: "<gray>You are now AFK."
  you-back: "<green>Welcome back!"
  kick-warning: "<yellow>You'll be kicked for being AFK in <seconds> seconds. Move to stay."
  list: "<gray>AFK players (<count>): <white><players>"
  none: "<gray>Nobody is AFK."
  check: "<white><name></white> <gray>has been inactive for <white><time></white>."

Requirements

  • Paper 1.21 (tested on 1.21.4; other 1.21.x Paper builds are expected to work)
  • Java 21
  • Folia is not supported yet

Installation

Full walkthrough: ClearAFK setup guide.

  1. Stop your server.
  2. Put ClearAFK-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearAFK/config.yml is created.
  4. Set afk-after and the kick options in the config, then run /afk reload.
