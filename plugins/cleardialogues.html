Why ClearDialogues

  • Branching choices: clickable chat choices jump to another node, run commands with %player%, or end the conversation.
  • No double rewards: one-time flags are saved per player, and old choice links expire once a choice is made.
  • Simple NPCs: no AI, invulnerable, silent and never despawn. They keep working after a restart.

Features

  • /dialogue npc create <dialogueId> spawns an NPC where you stand, with its name and (for villagers) profession from config
  • /dialogue npc remove removes the nearest one
  • Right-click to start the dialogue. Trading is blocked
  • MiniMessage lines typed out with a configurable delay
  • Nodes can run commands when they are shown
  • Per-choice permission or one-time conditions; locked choices shown greyed out or hidden
  • Ships with an example blacksmith conversation

Example config

# ClearDialogues. Create an NPC with /dialogue npc create <dialogueId> where you stand.
# Ticks between typed lines (20 ticks = 1 second).
line-delay: 30
# Show choices the player can't pick (greyed out) instead of hiding them.
show-locked-choices: true
messages:
  prefix: "<dark_gray>[<aqua>Dialogue</aqua>]</dark_gray> "
  choice: "  <click:run_command:'<command>'><hover:show_text:'Click to choose'><aqua>» <text></aqua></hover></click>"
  locked-choice: "  <dark_gray>» <strikethrough><text></strikethrough> <reason></dark_gray>"
  locked-permission: "(locked)"
  locked-once: "(already done)"
  ended: "<gray><italic>The conversation ends."
dialogues:
  blacksmith:
    npc-name: "<gold>Bram the Blacksmith"
    npc-type: VILLAGER           # any living mob type; villagers can also take a profession
    profession: WEAPONSMITH
    start: greet
    nodes:
      greet:
        lines:
          - "<gold>Bram:</gold> <white>Ah, a new face! Welcome to the forge."
          - "<gold>Bram:</gold> <white>What can I do for you?"
        choices:
          - text: "Tell me about this place."
            goto: lore
          - text: "Any free gifts for a newcomer?"
            goto: gift
            once: blacksmith_gift      # one-time flag per player
          - text: "VIP armour, please."
            permission: cleardialogues.vip
            commands: ["give %player% iron_chestplate 1"]
            goto: bye
          - text: "Goodbye."
            end: true
      lore:
        lines:
          - "<gold>Bram:</gold> <white>This forge has stood for three hundred years."
          - "<gold>Bram:</gold> <white>Every sword in town was born here."
        choices:
          - text: "Back"
            goto: greet
          - text: "Goodbye."
            end: true
      gift:
        lines:
          - "<gold>Bram:</gold> <white>Here, take these. Don't tell the others!"
        commands: ["give %player% iron_ingot 5"]   # run when this node is shown
        choices:
          - text: "Thanks!"
            goto: bye
      bye:
        lines:
          - "<gold>Bram:</gold> <white>Safe travels."

Installation

Full walkthrough: ClearDialogues setup guide.

  1. Stop your server.
  2. Put ClearDialogues-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearDialogues/config.yml is created.
  4. Write dialogues in the config (see the blacksmith example), then run /dialogue reload.
  5. Stand where the NPC should be and run /dialogue npc create <dialogueId>.
