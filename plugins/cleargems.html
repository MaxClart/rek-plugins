ClearGems

A gem for every player. Lose it in a fight, earn it back. Carry it for its passive effects, right-click it (or sneak + F) for its ability, and protect it, because every death takes a level.

Why ClearGems

  • 8 gems out of the box: Fire (fireball), Zephyr (dash), Might (strength), Heart (instant heal), Frost (slow and freeze), Shadow (invisibility), Tide (pull) and Earth (shockwave), all editable.
  • Death loss and rituals: a death drops the gem one level, at level 0 it's shattered, and an altar ritual or a Gem Upgrader brings it back.
  • Bound and dupe-proof: gems can't be dropped or stored, every gem has a unique ID saved to disk, and wrong or extra copies are deleted automatically.

Features

  • Passive potion effects while the gem is in your inventory, stronger at higher levels
  • Active ability on a cooldown, by right-click or sneak + swap-hands. Higher levels get shorter cooldowns and stronger abilities
  • Levels 1 to 3 by default (configurable)
  • Rituals at an altar block (lodestone by default) or with a craftable Gem Upgrader; costs and recipe configurable
  • Random gem on first join, or a fixed first gem, from a list you choose
  • Optional: the killer takes a level when they kill another player
  • Admin commands: give, set level, set type, reset, give upgraders, list and reload
  • All messages use MiniMessage

Tested

Tested on Paper 1.21.4 with three bots (one op, two not): every player got a gem on first join and got it back after an inventory clear; all 8 abilities, the passive effects and level scaling worked; cooldowns and the sneak + swap-hands trigger worked; each death dropped one level (keepInventory off and on) and level 0 disabled powers; the altar and Gem Upgrader repaired and upgraded gems and refused at max level; gems survived two restarts; a long list of dupe attempts (dropping, every container type, item frames, armour stands, allays, bundles, crafting, death and logout tricks) all failed; forged copies were deleted within 2 seconds; admin commands and killer-gains-level worked. Not tested: a plain chest (barrels, ender chests and shulker boxes go through the same check), logging out with the gem on the cursor, crafting the Gem Upgrader with its recipe, a full inventory when the gem is given back, creative-mode item copying, grave or corpse plugins, the exact number of fireballs at higher levels, and a real player client (all tests used bots).

Example config

# ClearGems. Gems SMP style ability gems for Paper 1.21.4.
# Each player owns exactly one gem. It is bound to them: it can't be dropped, put in any container
# (chests, ender chests, hoppers, droppers, shulkers, bundles), item frames, armour stands, or used in crafting.
# Every gem has a unique ID saved in data.yml. Any gem copy whose ID doesn't match the owner's saved ID is deleted.

# How a new player's gem is picked: RANDOM (from starting-gems) or FIRST (always the first in starting-gems).
assign-mode: RANDOM
# Gems that can be handed out on first join. Must be keys under "gems:" below.
starting-gems: [fire, zephyr, might, heart, frost, shadow, tide, earth]
# Level a new gem starts at, and the highest level.
start-level: 1
max-level: 3

# What happens when a player dies.
#  LOSE_LEVEL: the gem drops one level. At level 0 it is "shattered" (no passives, no ability) until repaired by a ritual.
#  NONE: nothing is lost.
# Either way the gem never drops on the ground; it's given back on respawn.
death-mode: LOSE_LEVEL
# If true, a player who kills another player gains a level (up to max-level).
killer-gains-level: false

# Ability triggers. Right-click the gem in either hand, and/or sneak + swap-hands key (F by default)
# with the gem anywhere in your inventory.
trigger-right-click: true
trigger-sneak-swap: true

# Passive effect amplifier by gem level (index 0 = level 1). 0 = effect level I, 1 = level II.
passive-amplifier-by-level: [0, 0, 1]
# How often passives are refreshed and inventories are checked for stray gem copies, in ticks (20 = 1 second).
check-interval-ticks: 40

# Rituals repair a shattered gem (level 0 -> 1) or upgrade it by one level.
ritual:
  # ALTAR: right-click the altar block while holding your gem, with the items in your inventory.
  # ITEM: right-click a Gem Upgrader item (crafted with the recipe below, or given by /gems giveupgrader).
  # BOTH: either works.
  mode: BOTH
  altar-block: LODESTONE
  # Items taken from the inventory for an altar ritual. MATERIAL: amount.
  repair-cost: {DIAMOND: 4}
  upgrade-cost: {DIAMOND: 8, NETHERITE_SCRAP: 1}
  # Gem Upgrader crafting recipe. 3 rows of 3 characters, space = empty. Set enabled: false to only allow /gems giveupgrader.
  upgrader-recipe:
    enabled: true
    shape: ["DND", "NSN", "DND"]
    ingredients: {D: DIAMOND_BLOCK, N: NETHERITE_SCRAP, S: NETHER_STAR}
  upgrader-material: NETHER_STAR
  upgrader-name: "<gradient:#ff9ad5:#9ad5ff><bold>Gem Upgrader</bold></gradient>"

# The gems. Key = gem id used in commands. You can add, remove or edit gems.
#  material: item used for the gem (pick one that can't be placed as a block).
#  passives: potion effects while the gem is in your inventory (level from passive-amplifier-by-level).
#  ability: FIREBALL, DASH, RAGE, HEAL, FREEZE, VANISH, PULL or SHOCKWAVE.
#  power: strength of the ability (meaning depends on the ability, grows with level).
#  radius: blocks, for FREEZE, PULL and SHOCKWAVE.  duration: seconds, for RAGE, FREEZE and VANISH.
#  cooldown: seconds at level 1; cooldown-per-level: seconds taken off for each level above 1.
gems:
  fire:

Installation

Full walkthrough: ClearGems setup guide.

  1. Stop your server.
  2. Put ClearGems-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearGems/config.yml is created.
  4. Edit gems, abilities, cooldowns, death mode and ritual costs in the config, then run /gems reload.
