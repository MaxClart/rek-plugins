Turn votes into players. ClearVotes hooks into NuVotifier and runs any commands you like when someone votes, with milestone and daily streak bonuses.

Why ClearVotes

  • Milestones: extra rewards at a player's 10th, 50th (or any) vote.
  • Daily streaks: bonus rewards for voting on consecutive days.
  • Offline queue: vote while offline and the rewards arrive on your next join.

Features

  • Any console commands per vote, with %player%
  • Broadcast message and clickable vote links on /vote, with the player's total and streak
  • /votes top leaderboard
  • /votes test <player> to try rewards without a vote site
  • /votes reset and /votes reload

Commands & permissions

CommandWhat it does
/voteClickable vote links, plus your total and streak
/votes topVote leaderboard
/votes test <player>Try rewards without a vote site
/votes reset, /votes reloadReset votes, reload the config

Dependencies

NuVotifier (free) is needed to receive votes from vote sites. Without it, /votes test still works.

PlaceholderAPI (new in 1.1.0)

Optional. If PlaceholderAPI is installed, ClearVotes registers these placeholders by itself (no eCloud download needed). Without it, ClearVotes loads and works as normal.

PlaceholderShows
%clearvotes_total%Total votes
%clearvotes_streak%Current vote streak in days
%clearvotes_queued%Rewards waiting to be given when the player is next online
%clearvotes_last%Date of the last vote, or never

Tested: Each placeholder was checked with /papi parse on Paper 1.21.4 with PlaceholderAPI 2.11.6 from the console. The plugin was also checked to load cleanly without PlaceholderAPI. Not yet checked with a player in game.

Tested

Tested on Paper 1.21.4 with bots using /votes test: rewards were given, /vote showed stats, an offline player's rewards were delivered on join, and /votes top listed both voters. Live votes from a vote site were not tested yet.

Example config

# ClearVotes. Receives votes from NuVotifier. Use /votes test <player> to try rewards without a vote site.
links:
  - "<aqua><click:open_url:'https://example.com/vote1'>Vote site 1</click>"
  - "<aqua><click:open_url:'https://example.com/vote2'>Vote site 2</click>"
broadcast: "<gold><player></gold> <yellow>voted on <service> and got a reward! /vote"
messages:
  thanks: "<green>Thanks for voting! You now have <total> votes."
  queued: "<green>You voted while offline. Here are your <count> reward(s)!"
# Commands run from console for every vote. %player% is replaced.
rewards:
  - "give %player% diamond 1"
  - "xp add %player% 100"
# Extra commands every Nth vote (by the player's total).
milestones:
  10:
    - "give %player% diamond_block 1"
  50:
    - "give %player% netherite_ingot 1"
# Daily streak: voting on consecutive days adds a bonus on these streak days.
streaks:
  3:
    - "give %player% golden_apple 1"
  7:
    - "give %player% enchanted_golden_apple 1"

Requirements

Installation

Full walkthrough: ClearVotes setup guide.

  1. Stop your server.
  2. Put ClearVotes-1.1.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearVotes/config.yml is created.
  4. Install NuVotifier and add your server to your vote sites.
  5. Set your rewards, milestones, streaks and vote links in the config, then run /votes reload.
  6. Try it with /votes test <player>.
