Why ClearKits

  • Live status: every kit in the menu shows Click to claim, Ready in 23h 59m, Already claimed or Locked.
  • Build in game: /kit create saves your inventory as a kit, enchantments and names included.
  • Survives restarts: cooldowns are saved to data.yml.

Features

  • Per-kit cooldowns in seconds, or one-time-only kits (cooldown -1)
  • First-join kit given automatically to brand-new players (configurable, or off)
  • Item rewards plus console commands with a %player% placeholder
  • Public kits, or a per-kit permission clearkits.kit.<name>
  • Full inventories: leftover items drop at the player's feet, never lost
  • MiniMessage colours in names, the menu title and all messages
  • Tab completion on every command

Commands & permissions

CommandPermission
/kits, /kit, /kit <kit>clearkits.use (everyone), plus clearkits.kit.<kit> for non-public kits
/kit create <name> <cooldownSeconds|-1>clearkits.admin (ops by default)
/kit delete <kit>, /kit give <player> <kit>clearkits.admin
/kit reset <player> [kit], /kit reloadclearkits.admin
Ignore cooldownsclearkits.bypass.cooldown (ops by default)

On Paper, server operators can use every kit and skip cooldowns by default.

Example config

# ClearKits - kits with cooldowns and a GUI.
# Each kit needs the permission clearkits.kit.<name> unless "public: true".
# cooldown is in seconds (0 = no cooldown, -1 = one time only).
messages:
  prefix: "<aqua>[Kits]</aqua> "
  claimed: "<green>You claimed the <kit> kit."
  cooldown: "<red>You can use <kit> again in <time>."
  one-time: "<red>You've already claimed <kit>. It's one time only."
  no-permission: "<red>You don't have access to that kit."
  unknown-kit: "<red>There is no kit called <kit>."
  inventory-full: "<yellow>Your inventory was full, so some items dropped at your feet."
gui:
  title: "<dark_aqua><bold>Kits"
  rows: 3
first-join-kit: starter    # given once to brand-new players ("" to turn off)
kits:
  starter:
    display: "<green>Starter"
    icon: STONE_SWORD
    slot: 10
    public: true
    cooldown: -1
    items:
      - {material: STONE_SWORD, amount: 1}
      - {material: STONE_PICKAXE, amount: 1}
      - {material: BREAD, amount: 16}
  daily:
    display: "<yellow>Daily"
    icon: GOLDEN_APPLE
    slot: 12
    public: true
    cooldown: 86400
    items:
      - {material: COOKED_BEEF, amount: 16}
      - {material: TORCH, amount: 32}
    commands:
      - "eco give %player% 100"
  vip:
    display: "<gold>VIP"
    icon: DIAMOND_CHESTPLATE
    slot: 14
    public: false
    cooldown: 604800
    items:
      - {material: DIAMOND_CHESTPLATE, amount: 1, name: "<gold>VIP Chestplate"}
      - {material: DIAMOND, amount: 8}

Installation

Full walkthrough: ClearKits setup guide.

  1. Stop your server.
  2. Put ClearKits-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearKits/config.yml is created.
  4. Edit the kits in the config, or hold the items you want and run /kit create <name> <cooldown>.
  5. Give non-public kits with the permission clearkits.kit.<name>, then run /kit reload after editing the file.
