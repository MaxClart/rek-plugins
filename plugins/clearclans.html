Why ClearClans

  • Roles: owner, officer and member, with /clan promote and /clan demote.
  • Clan chat and home: private chat by command or toggle, plus a shared /clan home with a don't-move delay.
  • Friendly fire: off by default, with a /clan ff toggle per clan.

Features

  • /clan create, invite (clickable accept/deny), accept, deny, leave, kick, disband
  • /clan info and a /clan top leaderboard by member count
  • Optional clan name in public chat (off by default), added in front of your existing chat format
  • Clan bank (deposit and withdraw) when Vault and an economy plugin are installed
  • Commented config.yml, MiniMessage text, data saved in data.yml

Tested

Tested on Paper 1.21.4 with two bots: creating a clan, invite and accept, /clan info, clan chat by command and toggle, /clan sethome and /clan home, friendly fire off and on, /clan top, and the optional chat tag. Example config

# ClearClans. Data is kept in data.yml.
# Clan names: allowed length.
name-min: 3
name-max: 16
max-members: 20
# Seconds before an invite expires.
invite-expire: 120
# Seconds to stand still before /clan home teleports (0 = instant).
home-delay: 3
# Default friendly fire for new clans (owners/officers can change it with /clan ff).
friendly-fire-default: false
# Put the clan name in front of public chat. Off by default so it does not clash with chat plugins
# such as ClearTags. When on, it wraps the existing chat format instead of replacing it.
chat-tag:
  enabled: false
  format: "<dark_gray>[<aqua><clan></aqua>]</dark_gray> "
# Clan bank needs Vault and an economy plugin. Without them, /clan bank is disabled.
bank-enabled: true
# MiniMessage text.
messages:
  prefix: "<dark_gray>[<aqua>Clans</aqua>]</dark_gray> "
  clan-chat: "<aqua>[Clan]</aqua> <gray><role></gray> <white><player></white><gray>:</gray> <message>"

Requirements

  • Paper 1.21.4
  • Java 21
  • Vault and an economy plugin (only for the clan bank)

Installation

Full walkthrough: ClearClans setup guide.

  1. Stop your server.
  2. Put ClearClans-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearClans/config.yml is created.
  4. Edit the member limit, home delay, friendly fire default and chat tag in the config, then run /clan reload.
  5. Optional: install Vault and an economy plugin to enable the clan bank.
