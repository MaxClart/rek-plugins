Why ClearOrders

  • Escrow: /order create takes the full amount up front and holds it until the order is filled or cancelled.
  • Partial fills: sellers sell what they have, up to what's still wanted, and get paid per item.
  • Built against duplication: menus never let items in or out, items are taken before money is paid, every click is re-checked and rate-limited, and data is saved after every transaction.

Features

  • /orders: a paged menu showing buyer, price each, amount still wanted and the total it pays
  • Sort by newest, highest price, lowest price or most wanted, and /orders search <item>
  • Bought items wait in the buyer's collection box: /orders collect
  • Cancel from "Your orders" or with /order cancel <id> to get back the money for the unfilled part
  • Max open orders per player, optional flat or percentage listing fee, min and max price, and an item blacklist
  • Only plain items (no custom names, enchantments or damage) can be sold into orders
  • Switches itself off with a clear console message if no economy plugin is found

Dependencies

Vault and an economy plugin (e.g. EssentialsX) are required.

Tested

Tested on Paper 1.21.4 with two bots, Vault 1.7.3 and EssentialsX 2.22.0: an order for 120 cobblestone at $2.00 each took $240 from the buyer, a seller filled 40 and was paid $80, a second fill spammed with fast clicks, shift-clicks, number-key swaps and double-clicks sold exactly the 40 items the seller had with nothing duplicated, /orders collect gave the buyer all 80 items, cancelling refunded the $80 left in escrow, and money and items added up at the end. With no economy plugin installed, ClearOrders disabled itself with a clear message. Sorting, search, paging, the max-orders limit and the listing fee were not bot-tested.

Example config

# ClearOrders. Needs Vault and an economy plugin (e.g. EssentialsX); without one the plugin disables itself.
# Max open orders per player (clearorders.bypass.limit ignores this).
max-orders: 5
max-amount: 100000
min-price: 0.01
max-price: 1000000
# Fee taken when creating an order (not refunded). Flat amount plus a percent of the order total.
listing-fee: 0
listing-fee-percent: 0
# Players can't fill their own orders.
block-self-fill: true
# Milliseconds between clicks in the menus (stops click spam).
click-cooldown-ms: 250
# Items that can't be ordered.
blacklist: [BEDROCK, BARRIER, COMMAND_BLOCK, STRUCTURE_BLOCK, SPAWNER, DEBUG_STICK]
currency: "$"
messages:
  prefix: "<dark_gray>[<aqua>Orders</aqua>]</dark_gray> "

Installation

Full walkthrough: ClearOrders setup guide.

  1. Stop your server.
  2. Put ClearOrders-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearOrders/config.yml is created.
  4. Install Vault and an economy plugin (e.g. EssentialsX) first.
  5. Edit max orders, listing fee, price limits and the blacklist in the config, then run /order reload.
