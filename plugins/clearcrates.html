Why ClearCrates

  • Chances shown: the preview lists each reward's real percentage, worked out from your weights.
  • Fixed slots: you choose every slot, nothing gets shuffled at random.
  • Lightweight: one small scheduled task per opening, with no packet tricks.

Features

  • Spin animation (length and sound configurable, or turn it off)
  • Right-click a key to open, left-click to preview
  • In-game editor: drag items in, close to save
  • Item and command rewards, with a %player% placeholder
  • MiniMessage colours in names and messages
  • Full inventories: rewards drop at the player's feet, never lost
  • Tab completion on every command

Commands & permissions

CommandPermission
/crate list, /crate preview <crate>clearcrates.use (everyone by default)
/crate give <player> <crate> [amount]clearcrates.admin (ops by default)
/crate edit <crate>, /crate setchance <crate> <slot> <chance>clearcrates.admin
/crate reloadclearcrates.admin

Optional hooks

PlaceholderAPI (%clearcrates_keys_<crate>%), ItemsAdder and Nexo items. None are required.

Example config

Chances are weights, so they don't need to add up to 100.

# ClearCrates - every chance is shown to players. Chances are weights; they don't need to add up to 100.
messages:
  prefix: "<gold>[Crates]</gold> "
  no-key: "<red>You need a <key> to open this crate."
  won: "<green>You won <reward>!"
  inventory-full: "<yellow>Your inventory was full, so the reward dropped at your feet."
animation:
  enabled: true
  ticks: 40          # length of the spin in ticks (20 = 1 second)
  sound: UI_BUTTON_CLICK
crates:
  vote:
    display: "<aqua><bold>Vote Crate"
    rows: 3
    key:
      material: TRIPWIRE_HOOK
      name: "<aqua>Vote Key"
    rewards:
      diamonds:
        slot: 10
        chance: 10
        material: DIAMOND
        amount: 3
        name: "<aqua>3 Diamonds"
      iron:
        slot: 12
        chance: 40
        material: IRON_INGOT
        amount: 16
        name: "<white>16 Iron Ingots"
      bread:
        slot: 14
        chance: 45
        material: BREAD
        amount: 32
        name: "<yellow>32 Bread"
      money:
        slot: 16
        chance: 5
        material: GOLD_BLOCK
        amount: 1
        name: "<gold>$1,000"
        give-item: false
        commands:
          - "eco give %player% 1000"

Requirements

  • Paper 1.21 (tested on 1.21.4; other 1.21.x Paper builds are expected to work)
  • Java 21
  • Folia is not supported yet

Installation

Full walkthrough: ClearCrates setup guide.

  1. Stop your server.
  2. Put ClearCrates-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearCrates/config.yml is created.
  4. Edit the config or use /crate edit <crate> in game, then run /crate reload.
  5. Give keys with /crate give <player> <crate> [amount].
