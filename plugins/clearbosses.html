Why ClearBosses

  • Phases: at health percentages, each with a message and actions: minions, potion effects, knockback, area damage, lightning or heal.
  • Fair rewards: reward only the top damager, or everyone who did at least a set percentage of the damage.
  • No leftovers: bosses never despawn or burn in daylight, and bosses and minions are removed when the server stops.

Features

  • Mob type, MiniMessage name, health, attack damage, speed, knockback resistance and equipment in config.yml
  • Boss bar showing the boss's health to players within a set range
  • Loot table with amounts and percentage chances, plus console reward commands with %player%
  • /boss list with live health and location
  • Optional timed spawns at fixed locations
  • Ships with two example bosses: Zombie King and Witch Queen

Commands & permissions

CommandPermission
/boss spawn <id> [here | <world> <x> <y> <z>]clearbosses.admin (ops by default)
/boss list, /boss kill [id|all], /boss reloadclearbosses.admin

/boss spawn <id> alone spawns at the block you're looking at. The world and coordinates form works from the console.

Dependencies

None.

Tested

Tested on Paper 1.21.4 with a bot: a 40-health test boss spawned with its boss bar, going past 50% health showed the phase message and summoned 2 minions, killing it removed the boss bar and gave 3 diamonds from the loot table and 2 gold ingots from the reward command, /boss list and /boss kill worked, and after a restart no bosses or minions were left. Timed spawns, the knockback, damage, lightning and heal actions, top-damager mode with several players, and the Witch Queen example were not bot-tested.

Example config

# ClearBosses. Bosses never despawn, and all bosses and minions are removed when the server stops
# (any left behind after a crash are removed when their chunk loads).
broadcast-spawn: "<dark_red><bold>BOSS</bold></dark_red> <name> <red>has appeared!"
broadcast-death: "<dark_red><bold>BOSS</bold></dark_red> <name> <green>was slain! Top damage: <gold><top></gold>"
bosses:
  zombie_king:
    type: ZOMBIE                 # any living mob type
    name: "<gold><bold>Zombie King"
    health: 300
    damage: 8                    # attack damage (mobs that attack)
    speed: 0.28                  # movement speed (optional)
    knockback-resistance: 0.8    # 0-1 (optional)
    equipment:                   # helmet, chestplate, leggings, boots, hand, offhand
      helmet: GOLDEN_HELMET
      chestplate: NETHERITE_CHESTPLATE
      hand: NETHERITE_SWORD
    bossbar:
      color: YELLOW              # PINK, BLUE, RED, GREEN, YELLOW, PURPLE, WHITE
      range: 40                  # players within this many blocks see the bar
    # Phases fire once each when health drops to or below "at" percent.
    # Actions: minions <TYPE> <count> | effect <EFFECT> <seconds> <level> | knockback <radius> <strength>
    #          damage <radius> <amount> | lightning <radius> (strikes players in radius) | heal <amount>
    phases:
      - at: 60
        message: "<gold>Zombie King: <yellow>Rise, my servants!"
        actions: ["minions ZOMBIE 3"]
      - at: 30
        message: "<gold>Zombie King: <red>ENOUGH!"
        actions: ["effect SPEED 30 1", "knockback 6 1.5", "lightning 8"]
    # Rewards. mode: top = only the top damager; share = everyone who did at least min-percent of the damage.
    reward-mode: share
    min-percent: 10
    replace-drops: true          # remove the mob's vanilla drops
    xp: 200
    loot:                        # rolled for each rewarded player; chance is a percentage
      - {item: DIAMOND, amount: "2-5", chance: 100}
      - {item: NETHERITE_INGOT, amount: "1", chance: 15}
    commands:                    # run from console for each rewarded player
      - "xp add %player% 100"
  witch_queen:
    type: WITCH
    name: "<light_purple><bold>Witch Queen"
    health: 200
    damage: 6
    bossbar: {color: PURPLE, range: 40}
    phases:
      - at: 50
        message: "<light_purple>Witch Queen: <gray>Come, my pets."
        actions: ["minions SPIDER 2", "damage 6 4"]
    reward-mode: top
    loot:
      - {item: EMERALD, amount: "4-8", chance: 100}
    commands: []
# Timed spawns. Leave empty for none. A spawn is skipped while that boss is still alive there.
timed-spawns: []

#    world: world
#    x: 0
#    y: 70
#    z: 0
#    every-minutes: 120

Installation

Full walkthrough: ClearBosses setup guide.

  1. Stop your server.
  2. Put ClearBosses-1.0.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearBosses/config.yml is created.
  4. Add bosses under bosses: in the config (see the commented examples), then run /boss reload.
  5. Spawn one with /boss spawn <id>.
