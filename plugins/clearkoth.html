Why ClearKoth

  • Fair captures: a player alone on the hill counts down the capture time. Two or more players makes it contested and the timer pauses.
  • Live boss bar: shows the hill, the capper and the time left, plus broadcasts on start, progress and win.
  • Set and forget: list daily start times (HH:mm, server local time) and hills start themselves.

Features

  • Cuboid hills: select with /koth pos1 and /koth pos2 (or the /koth wand), then /koth create <name>
  • Optional reset: progress resets when the capper leaves (reset-on-leave, on by default)
  • Rewards: any console commands on win, with %player% and %hill%
  • Win counts saved in data.yml, with a /koth top leaderboard
  • Optional time limit that ends the event with no winner
  • /koth start <name> [seconds], stop, list, delete and reload
  • All messages use MiniMessage and can be edited

PlaceholderAPI (new in 1.1.0)

Optional. If PlaceholderAPI is installed, ClearKoth registers these placeholders by itself (no eCloud download needed). Without it, ClearKoth loads and works as normal.

PlaceholderShows
%clearkoth_active%Name of the running hill, or none
%clearkoth_running%yes or no
%clearkoth_time_left%Seconds left to capture (0 when nothing is running)
%clearkoth_time_left_formatted%Time left as m:ss, or -
%clearkoth_capper%Player currently capturing, or none
%clearkoth_wins%The player's total KOTH wins
%clearkoth_top_<n>_name% / %clearkoth_top_<n>_wins%Leaderboard position n (e.g. top_1_name), - / 0 if empty

Tested: Checked with /papi parse on Paper 1.21.4 with PlaceholderAPI 2.11.6 before, during and after a bot captured a hill (active, running, time left, capper, wins and top 1 all updated; an empty slot such as top 5 showed -). The plugin was also checked to load cleanly without PlaceholderAPI.

Tested

Tested on Paper 1.21.4 with bots: a hill was created with pos1/pos2, a 10-second event was won by a bot standing alone in the zone and the reward commands ran, a second bot entering made it contested and the timer paused until it left, /koth top showed the win count, and a scheduled start time fired on time and was won. The wand, delete, reload, reset-on-leave and the time limit were not bot-tested.

Example config

# ClearKoth. Create a hill with /koth wand (or /koth pos1 + /koth pos2), then /koth create <name>.
# Seconds a player must hold the hill alone to win (default for /koth start <name>).
capture-seconds: 180
# Event ends with no winner after this many seconds (0 = never).
max-duration: 1800
# If the capper leaves the hill, reset their progress to 0 (false = keep progress, it just pauses).
reset-on-leave: true
# Broadcast progress every N seconds while someone is capturing (0 = off).
progress-broadcast-every: 30
# Boss bar colour: PINK, BLUE, RED, GREEN, YELLOW, PURPLE, WHITE
bossbar-color: RED
# Commands run from console when someone wins. %player% and %hill% are replaced.
rewards:
  - "give %player% diamond 5"
  - "xp add %player% 500"
# Auto-start schedule (server local time, HH:mm). Hill must exist. Leave empty for none.
schedule:
#  - time: "18:00"
#    hill: "spawn"
#    seconds: 180
# MiniMessage text. Placeholders: <hill>, <player>, <time>
messages:
  prefix: "<dark_gray>[<red>KOTH</red>]</dark_gray> "
  start: "<yellow>King of the hill has started at <gold><hill></gold>! Hold it for <time>s to win."
  progress: "<gold><player></gold> <yellow>is capturing <hill>: <time>s left!"
  win: "<gold><player></gold> <green>has captured <hill> and won!"
  stopped: "<red>The KOTH at <hill> has ended with no winner."
  bossbar-idle: "<red><hill></red> <gray>- nobody capturing"
  bossbar-capping: "<red><hill></red> <gray>- <gold><player></gold> <gray>capturing - <white><time>s</white> left"
  bossbar-contested: "<red><hill></red> <gray>- <dark_red>CONTESTED</dark_red> <gray>(<player>, <time>s left)"

Installation

Full walkthrough: ClearKoth setup guide.

  1. Stop your server.
  2. Put ClearKoth-1.1.0.jar in your plugins/ folder.
  3. Start the server so plugins/ClearKoth/config.yml is created.
  4. Stand at one corner of your hill and run /koth pos1, then at the opposite corner run /koth pos2. Include some height.
  5. Run /koth create <name>, then /koth start <name> [seconds].
  6. Edit capture time, rewards and schedule in the config, then run /koth reload.
