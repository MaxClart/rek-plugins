FAQ

Refunds

Plugins are digital goods, so all sales are normally final once the file has been sent. If something doesn't work on your server, open an issue first and we'll help you fix it. If we genuinely can't get it working on a supported setup, get in touch and we'll sort out a fair solution.

Server owner FAQ

Which server software is supported?

Every plugin runs on Paper 1.21 (tested on 1.21.4) with Java 21. Folia isn't supported yet. Spigot and Bukkit aren't tested.

Does it need other plugins?

ClearKits, ClearDaily, ClearAFK and ClearTags have no dependencies (ClearTags works best with a permissions plugin such as LuckPerms). For ClearCrates, PlaceholderAPI, ItemsAdder and Nexo are optional hooks. ClearVotes needs NuVotifier (free) to receive votes from vote sites. ClearKoth, ClearStaff and ClearChat have no dependencies. ClearClans needs Vault and an economy plugin only for its clan bank, and ClearSpawners only for Sell all.

How many plugins are there?

Eleven: ClearCrates, ClearKits, ClearDaily, ClearAFK, ClearTags, ClearVotes, ClearKoth, ClearClans, ClearStaff, ClearSpawners and ClearChat.

Are the plugins made with AI?

ClearForge plugins are built with AI assistance and tested on a real Paper 1.21 server.

Can I use it on more than one server?

One purchase covers one server network (e.g. a proxy with its backend servers). Please don't redistribute or resell it.

How do I pay?

With Bitcoin through Sell.app, which gives you an instant automatic download. See the Buy section on each plugin page.

How fast do I get the plugin?

Instantly. As soon as Sell.app confirms your Bitcoin payment, the download is delivered automatically.

Where do I report bugs?

GitHub issues.
