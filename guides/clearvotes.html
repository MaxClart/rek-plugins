ClearVotes setup guide

Set up vote rewards, milestones, streaks and vote links.

Buy ClearVotes — $6.99 Plugin page

1. Install

Follow the getting started guide: put ClearVotes-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearVotes/config.yml.

NuVotifier is required for real votes. ClearVotes receives votes from NuVotifier (free). Install and set it up first, then add your server to your vote sites. Without it, only /votes test works.
Live votes from vote sites haven't been tested yet. Testing used /votes test.

2. Configure rewards

Put your real vote site links in links (clickable on /vote):

links:
  - "<aqua><click:open_url:'https://example.com/vote1'>Vote site 1</click>"

rewards are console commands run for every vote, with %player%:

rewards:
  - "give %player% diamond 1"
  - "xp add %player% 100"
milestones:
  10:
    - "give %player% diamond_block 1"
streaks:
  3:
    - "give %player% golden_apple 1"
  • milestones: extra commands when a player reaches that vote total (10th, 50th, or any number).
  • streaks: bonus commands on those days of a daily voting streak.
  • broadcast and messages (thanks, queued) set the texts.

3. First commands

  • /votes test Steve sends a test vote for Steve, so you can check rewards without a vote site.
  • /vote shows the links and your total and streak.
  • /votes top shows the leaderboard.
  • /votes reset Steve resets Steve's votes.
  • /votes reload reloads the config.

4. Permissions

  • clearvotes.use: vote links and stats. Everyone by default.
  • clearvotes.admin: test, reset and reload. Ops by default, e.g. /lp user <player> permission set clearvotes.admin true.

Common questions

What if a player votes while offline?

Their rewards are queued and given when they next join.

Does it work without NuVotifier?

Only /votes test works. Real votes from sites need NuVotifier.
