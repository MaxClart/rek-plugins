ClearKoth setup guide

Mark out a hill, run king of the hill events and schedule them to start by themselves.

Buy ClearKoth — $8.99 Plugin page

1. Install

Follow the getting started guide: put ClearKoth-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearKoth/config.yml.

2. Mark out a hill

  1. Stand at one corner of your hill and type /koth pos1.
  2. Go to the opposite corner and type /koth pos2. Include some height so players standing on it are inside.
  3. Or use /koth wand: left-click a block for pos1, right-click for pos2.
  4. Save it with /koth create spawn.

3. Start an event

/koth start spawn uses the default capture time, or /koth start spawn 120 for 120 seconds. A player alone on the hill counts down. If a second player steps on, it's contested and the timer pauses. /koth stop ends it early.

4. Config

capture-seconds: 180
max-duration: 1800
reset-on-leave: true
rewards:
  - "give %player% diamond 5"
schedule:
  - time: "18:00"
    hill: "spawn"
    seconds: 180
  • capture-seconds: how long a player must hold the hill alone.
  • max-duration: the event ends with no winner after this many seconds (0 = never).
  • reset-on-leave: progress goes back to 0 when the capper leaves.
  • rewards: console commands, with %player% and %hill%.
  • schedule: daily start times in server local time. The hill must exist.

Save, then run /koth reload. Hills and win counts are kept in plugins/ClearKoth/data.yml.

5. Permissions

  • clearkoth.use: /koth list and /koth top. Everyone by default.
  • clearkoth.admin: everything else. Ops by default, e.g. /lp user <player> permission set clearkoth.admin true.

Common questions

Does it support PlaceholderAPI?

No, PlaceholderAPI is not supported.

What was tested?

Creating a hill with pos1/pos2, winning an event, contested pausing, /koth top and a scheduled start were tested with bots on Paper 1.21.4. The wand, delete, reload, reset-on-leave and the time limit were not bot-tested.
