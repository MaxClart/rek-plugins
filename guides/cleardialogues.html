ClearDialogues setup guide

Create a talking NPC with branching, clickable choices and rewards.

Buy ClearDialogues — $6.99 Plugin page

1. Install

Follow the getting started guide: put ClearDialogues-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearDialogues/config.yml.

2. Write a dialogue

Open plugins/ClearDialogues/config.yml and copy the blacksmith example. Each dialogue is made of nodes with MiniMessage lines. Choices can use text, goto <node>, commands [...], end: true, permission <perm> and once <flag>. Then run /dialogue reload.

3. Place the NPC

Stand where it should be and run /dialogue npc create blacksmith. Players right-click it to talk. /dialogue npc remove removes the nearest one within 5 blocks. /dialogue start blacksmith Steve starts a dialogue without an NPC.

4. Permissions

  • cleardialogues.use: talk to NPCs. Everyone by default.
  • cleardialogues.admin: everything else. Ops by default.

One-time flags are stored on the player, so they survive restarts.

Common questions

Does it work with Citizens?

No, there is no Citizens support. ClearDialogues spawns its own simple NPCs.

What was tested?

Creating an NPC, typed lines, clickable choices, a reward, one-time locks, expired links, restarts and NPC removal were tested with a bot on Paper 1.21.4. The permission lock was not tested with a player lacking the permission.
