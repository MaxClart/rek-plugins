ClearGems setup guide

Set up Gems SMP style ability gems with levels, death loss and rituals.

Buy ClearGems — $7.99 Plugin page

1. Install

Follow the getting started guide: put ClearGems-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearGems/config.yml.

2. How it works

  • Every player gets one gem the first time they join with ClearGems installed: random from starting-gems, or the first one with assign-mode: FIRST.
  • Keep the gem anywhere in your inventory for its passive effects. Right-click it, or sneak + press the swap-hands key (F), to use its ability.
  • Dying takes the gem down one level (death-mode: LOSE_LEVEL). At level 0 it's shattered: no passives, no ability. The gem comes back on respawn.

3. Rituals

Right-click the altar block (lodestone by default) while holding your gem with the cost items in your inventory, or right-click a Gem Upgrader. A ritual repairs a shattered gem to level 1 or upgrades it by one level. Costs and the upgrader recipe are in the config.

4. Config

Edit plugins/ClearGems/config.yml (gems, abilities, cooldowns, death mode, ritual costs), then run /gems reload. Gem data is kept in plugins/ClearGems/data.yml, saved on every change.

5. Admin commands

  • /gems give Steve fire 2, /gems set Steve level 3, /gems set Steve type frost
  • /gems reset Steve, /gems giveupgrader Steve 1, /gems list
  • /gems info Steve shows anyone's gem, level and ID (cleargems.info.others).

Admin commands need cleargems.admin (ops by default). /gems give makes a new ID, so the old gem item becomes invalid.

Common questions

Can players duplicate gems?

Gems can't be dropped, put in containers, bundles, item frames or armour stands, given to mobs or used in crafting, and every 2 seconds (and on join, respawn and inventory close) any gem with the wrong ID or owner, or an extra copy, is deleted. Every dupe attempt in testing failed.

What was tested?

Gem assignment, all 8 abilities, passives, cooldowns, death loss, rituals, the Gem Upgrader, restarts, a long list of dupe attempts, forged copies and admin commands were tested with three bots on Paper 1.21.4. Not tested: a plain chest, logging out with the gem on the cursor, crafting the Gem Upgrader with its recipe, a full inventory when the gem is given back, creative-mode item copying, grave or corpse plugins, the exact number of fireballs at higher levels, and a real player client (all tests used bots).
