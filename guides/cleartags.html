ClearTags setup guide

Set up chat tags that players unlock by permission and pick from a menu.

Buy ClearTags — $5.99 Plugin page

1. Install

Follow the getting started guide: put ClearTags-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearTags/config.yml.

2. Configure tags and chat format

chat-format: "<tag><name><gray>: </gray><message>"   # <tag> is empty when no tag is equipped
menu-title: "<dark_gray>Choose your tag"
tags:
  vip:
    display: "<gold>[VIP] "
    icon: GOLD_INGOT
    description: "For our supporters"

Each tag has an id (here vip), a display shown in chat (MiniMessage, so colours and gradients work), an icon for the menu and a description. Add as many as you like. Texts are under messages.

3. First commands

  • /tags opens the menu. /tags vip equips a tag, /tags clear removes it.
  • /tags set Steve vip sets Steve's tag, /tags set Steve none removes it.
  • /tags reload reloads the config.

4. Permissions

Players need cleartags.tag.<id> to equip a tag, or cleartags.tag.* for all. Pair it with a permissions plugin such as LuckPerms:

  • /lp user <player> permission set cleartags.tag.vip true
  • /lp group vip permission set cleartags.tag.vip true

cleartags.use (open the menu) is on for everyone, and cleartags.admin (set and reload) is for ops by default.

Common questions

Why does a tag show as grey dye?

The player hasn't unlocked it yet: give them its permission.

Is a database needed?

No, the equipped tag is saved on the player.
