ClearClans setup guide

Let players create and run their own clans, with roles, clan chat, a home and friendly fire.

Buy ClearClans — $8.99 Plugin page

1. Install

Follow the getting started guide: put ClearClans-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearClans/config.yml.

2. Your first clan

  1. /clan create Wolves creates a clan with you as owner.
  2. /clan invite Steve sends a clickable invite. Steve runs /clan accept (or /clan deny).
  3. /clan info shows members and roles. /clan promote Steve and /clan demote Steve change roles.

3. Chat, home and friendly fire

  • /clan chat hello sends one message to the clan. /clan chat on its own toggles all your messages into clan chat.
  • /clan sethome then /clan home. Players must stand still for the configured delay.
  • /clan ff toggles friendly fire for your clan. It's off by default.

4. Config

Edit plugins/ClearClans/config.yml (member limit, home delay, friendly fire default, chat tag, messages), then run /clan reload. Data is kept in plugins/ClearClans/data.yml.

5. Optional clan bank

Install Vault and an economy plugin to enable /clan bank deposit 100, /clan bank withdraw 100 and /clan top bank.

What was tested?

Create, invite, accept, info, clan chat, home, friendly fire, /clan top and the chat tag were tested with two bots on Paper 1.21.4. The clan bank was not tested (no economy plugin was installed), and kick, promote and demote were not bot-tested.
