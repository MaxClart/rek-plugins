ClearKits setup guide

Set up a starter kit, a daily kit and VIP kits with cooldowns and a click-to-claim menu.

Buy ClearKits — $7.99 Plugin page

1. Install

Follow the getting started guide: put ClearKits-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearKits/config.yml.

2. Configure your kits

Each kit under kits has a display name, an icon, a menu slot, public, a cooldown, items and optional commands.

  • cooldown is in seconds: 0 means no cooldown, -1 means one time only, 86400 is one day.
  • public: true means everyone can use it. Otherwise players need clearkits.kit.<name>.
  daily:
    display: "<yellow>Daily"
    icon: GOLDEN_APPLE
    slot: 12
    public: true
    cooldown: 86400
    items:
      - {material: COOKED_BEEF, amount: 16}
      - {material: TORCH, amount: 32}
    commands:
      - "eco give %player% 100"

first-join-kit: starter gives the starter kit once to brand-new players. Set it to "" to turn it off. The menu title and size are under gui (title, rows).

3. First commands

  • /kits opens the menu, /kit daily claims the daily kit.
  • Hold the items you want, then /kit create pvp 3600 saves your inventory as a kit called pvp with a one-hour cooldown. Use -1 for one time only.
  • /kit give Steve vip gives Steve the VIP kit, ignoring the cooldown.
  • /kit reset Steve daily resets Steve's cooldown for one kit (leave the kit out to reset all).
  • /kit delete pvp deletes a kit, /kit reload reloads the config.

4. Permissions

  • clearkits.use: open the menu and claim kits you can access. Everyone by default.
  • clearkits.kit.<name>: access to a non-public kit, e.g. /lp user <player> permission set clearkits.kit.vip true. clearkits.kit.* gives every kit.
  • clearkits.bypass.cooldown: ignore cooldowns. Ops by default.
  • clearkits.admin: create, delete, give, reset and reload. Ops by default.

Common questions

Why can I claim every kit with no cooldown?

On Paper, ops have every kit and ignore cooldowns by default. Test with a non-op account.

Do cooldowns survive a restart?

Yes, they're saved to data.yml.

Full inventory?

Leftover items drop at the player's feet.
