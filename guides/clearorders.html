ClearOrders setup guide

Set up a player-run buy order market with escrow and partial fills.

Buy ClearOrders — $5.99 Plugin page

1. Install

Follow the getting started guide: put ClearOrders-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearOrders/config.yml.

2. Install Vault and an economy

ClearOrders needs Vault and an economy plugin such as EssentialsX. Without one, it disables itself and says so in the console.

3. Config

Edit plugins/ClearOrders/config.yml (max orders, listing fee, price limits, blacklist), then run /order reload. Data is kept in plugins/ClearOrders/orders.yml and saved after every transaction.

4. How players use it

  • /order create cobblestone 120 2 posts an order for 120 cobblestone at $2 each. The $240 total is held in escrow.
  • /orders opens the menu. Click an order to sell your matching items. /orders search cobblestone filters, and /orders mine shows your own orders.
  • /orders collect takes the items bought for you. Anything that doesn't fit stays in the box.
  • /order cancel <id> (or click it in "Your orders") refunds the unfilled part.

Only plain items (no custom names, enchantments or damage) can be sold into orders.

5. Permissions

  • clearorders.use: everyone by default.
  • clearorders.admin: reload and cancel any order. Ops by default.
  • clearorders.bypass.limit: ignore the max-orders limit.

Common questions

What was tested?

Escrow, partial fills, payment, duplication attempts with fast clicks, shift-clicks, number-key swaps and double-clicks, collecting, cancelling with a refund, and the no-economy shutdown were tested with two bots on Paper 1.21.4 with Vault and EssentialsX. Sorting, search, paging, the max-orders limit and the listing fee were not bot-tested.
