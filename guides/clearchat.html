ClearChat setup guide

Set up the word filter, anti-spam, caps and link blocking, and mentions.

Buy ClearChat — $7.99 Plugin page

1. Install

Follow the getting started guide: put ClearChat-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearChat/config.yml.

2. Config

Edit plugins/ClearChat/config.yml: filter words, cooldown, caps limit, link whitelist and mention sound. Then run /chat reload.

3. Staff commands

  • /chat clear wipes chat for players without the bypass.
  • /chat mute mutes global chat (run it again to unmute).
  • /chat reload reloads the config.

These need clearchat.admin (ops by default).

4. Bypass permissions

Ops have these by default: clearchat.bypass.filter, .cooldown, .duplicate, .caps, .links, .mute, .clear, or clearchat.bypass.* for all. For example /lp user <player> permission set clearchat.bypass.links true.

Common questions

Does it replace my chat format?

No. ClearChat only changes the message text, so plugins such as ClearTags keep working. Its own chat format is off by default and skipped when ClearTags is installed.

What was tested?

Censoring, cooldown, duplicate block, caps lowering, link and IP blocking, mentions, /chat mute, /chat clear and op bypass were tested with bots on Paper 1.21.4 alongside ClearTags. Block mode for the filter and caps, and ClearChat's own optional chat format, were not bot-tested.
