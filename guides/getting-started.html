Getting started

How to install any ClearForge plugin on a Paper 1.21 server, the right way.

What you need

  • A Paper 1.21 server (our plugins are tested on Paper 1.21.4). Folia isn't supported yet.
  • Java 21.
  • Access to your server's files (FTP or your host's file manager) and console.

1. Download the jar

After you pay, Sell.app sends you a delivery email and shows a delivery page. Download the plugin's .jar file from there (for example ClearKits-1.0.0.jar).

2. Put it in /plugins

  1. Stop your server.
  2. Upload the jar into the plugins/ folder of your server.

3. Restart, don't /reload

Start the server again with a full restart. Avoid /reload: it can leave plugins in a broken state. After you edit a config later, use the plugin's own reload command instead (each guide lists it).

4. Check the console

Watch the console while the server starts. You should see the plugin being enabled. Red errors that mention the plugin name mean something is wrong, see troubleshooting below. In game, /plugins lists it in green when it's loaded.

5. Find config.yml

On first start the plugin creates plugins/<PluginName>/config.yml, for example plugins/ClearKits/config.yml. Every config is commented. Edit it, save, then run the plugin's reload command.

6. Give permissions

Each plugin's player permission is on for everyone by default, and admin permissions are for ops by default. To give extra permissions, use a permissions plugin. LuckPerms is a common free option:

  • One player: /lp user Steve permission set clearkits.kit.vip true
  • A whole group: /lp group vip permission set clearkits.kit.vip true

Troubleshooting

Wrong Java version

If the console says the plugin was compiled for a newer Java version (an "UnsupportedClassVersionError"), your server isn't on Java 21. Switch to Java 21 in your host's panel, or install it, and restart.

Plugin not loading

  • Check the jar is directly in plugins/, not in a subfolder, and ends in .jar.
  • Check you're running Paper 1.21, not Spigot, Bukkit or Folia.
  • Restart fully and read the first error in the console that mentions the plugin.

Permissions not working

  • Check the node is spelt exactly as in the guide.
  • Ops have admin permissions by default; test with a non-op account too.
  • With LuckPerms, check what a player has with /lp user <player> permission info.

Still stuck? Open an issue on GitHub with the console error.
