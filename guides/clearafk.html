ClearAFK setup guide

Set up AFK detection that AFK pools and piston loops can't fool.

Buy ClearAFK — $4.99 Plugin page

1. Install

Follow the getting started guide: put ClearAFK-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearAFK/config.yml.

2. Configure detection and kicks

afk-after: 300            # seconds without activity before a player is marked AFK
kick:
  enabled: true
  after: 900              # seconds AFK (after being marked AFK) before kicking
  only-when-full: false   # only kick AFK players when the server is at max players
  message: "<red>You were kicked for being AFK too long."
announce: true            # broadcast when players go AFK / come back
tab-tag:
  enabled: true
  format: "<gray>[AFK] </gray><name>"
  • Set kick.enabled: false if you never want to kick AFK players, or only-when-full: true to kick only when the server is full.
  • Players get a warning in the last 30 seconds before a kick.
  • Only real activity resets the timer: turning your head, chatting, commands, interacting, and breaking or placing blocks. Being pushed by water, pistons or vehicles doesn't count.

3. First commands

  • /afk sets yourself AFK by hand.
  • /afk list shows who's AFK.
  • /afk check Steve shows how long Steve has been inactive.
  • /afk reload reloads the config.

4. Permissions

  • clearafk.use and clearafk.list: everyone by default.
  • clearafk.admin: reload. Ops by default.
  • clearafk.bypass.kick: never kicked. Ops by default. Give it to staff with /lp user <player> permission set clearafk.bypass.kick true.
  • clearafk.bypass: never marked AFK automatically. Nobody by default.

Common questions

Why wasn't I kicked while testing?

Ops have clearafk.bypass.kick by default. Test with a non-op account.
