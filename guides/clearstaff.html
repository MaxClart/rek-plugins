ClearStaff setup guide

Set up vanish, freeze, invsee, staff chat and the punishment menu for your staff team.

Buy ClearStaff — $9.99 Plugin page

1. Install

Follow the getting started guide: put ClearStaff-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearStaff/config.yml.

2. Give staff permissions

All permissions default to op. For non-op staff, give them what they need, e.g. /lp user Steve permission set clearstaff.* true for everything, or single nodes like clearstaff.vanish, clearstaff.freeze, clearstaff.punish.

3. Everyday tools

  • /vanish (or /v) hides you. Staff with clearstaff.vanish.see still see you.
  • /freeze Steve stops Steve moving and using commands (except the whitelist).
  • /invsee Steve and /endersee Steve are read-only unless you have clearstaff.invsee.edit.
  • /sc hello for staff chat, or /sc to toggle.

4. Punishments

/punish Steve opens a menu of your presets (warn, mute, kick, temp ban, ban). Edit durations, icons and reasons in plugins/ClearStaff/config.yml, then /clearstaff reload. Bans use the server ban list, so /pardon Steve removes them. /unmute Steve lifts a mute and /history Steve shows past punishments.

What was tested?

Vanish, freeze (movement and commands), invsee, endersee, staff chat, the punish menu, the mute and 1-day temp ban presets, /pardon, /unmute and /history were tested with two bots on Paper 1.21.4. Read-only mode, damage blocking while frozen, the warn, kick and permanent ban presets, and mute expiry were not bot-tested.
