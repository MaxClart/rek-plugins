ClearDaily setup guide

Set up a daily login rewards calendar with streaks.

Buy ClearDaily — $4.99 Plugin page

1. Install

Follow the getting started guide: put ClearDaily-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearDaily/config.yml.

2. Configure the calendar

timezone: "Europe/London"     # when the "day" rolls over
reset-on-miss: true           # missing a whole day sends the player back to day 1
loop: true                    # after the last day, start again from day 1
remind-on-join: true          # tell players on join when a reward is waiting

Set timezone to your players' timezone. Turn off reset-on-miss if you don't want streaks to reset, and loop if the calendar should stop after the last day.

Rewards go under days, up to 45 days. Each day has an icon, a name, and items and/or commands (with %player%):

days:
  1: {icon: BREAD, name: "<white>16 Bread", items: [{material: BREAD, amount: 16}]}
  3: {icon: GOLD_INGOT, name: "<yellow>$250", commands: ["eco give %player% 250"]}

Unlisted day numbers in between are skipped. The menu title is gui.title, and all texts are under messages.

3. First commands

  • /daily (or /rewards) opens the calendar.
  • /daily setday Steve 5 moves Steve to day 5.
  • /daily reset Steve resets Steve's streak.
  • /daily reload reloads the config.

4. Permissions

  • cleardaily.use: open the calendar and claim. Everyone by default.
  • cleardaily.admin: reset, setday and reload. Ops by default, e.g. /lp user <player> permission set cleardaily.admin true.

Common questions

When does a new day start?

At midnight in the timezone you set.

Is progress saved?

Yes, in data.yml, so it survives restarts.
