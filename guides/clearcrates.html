ClearCrates setup guide

Set up your first crate, give out keys and show players the exact drop chances.

Buy ClearCrates — $9.99 Plugin page

1. Install

Follow the getting started guide: put ClearCrates-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearCrates/config.yml.

2. Configure your first crate

The default config comes with a crate called vote. Each crate has a display name, rows for the menu size, a key item and a list of rewards.

crates:
  vote:
    display: "<aqua><bold>Vote Crate"
    rows: 3
    key:
      material: TRIPWIRE_HOOK
      name: "<aqua>Vote Key"

Each reward has a slot (where it sits in the preview), a chance, the material, amount and name. Chances are weights, so they don't need to add up to 100: the preview works out the real percentage for players.

For a command reward, such as money, set give-item: false and add commands. %player% is replaced with the winner's name:

      money:
        slot: 16
        chance: 5
        material: GOLD_BLOCK
        amount: 1
        name: "<gold>$1,000"
        give-item: false
        commands:
          - "eco give %player% 1000"

Under animation you can set enabled, the spin length in ticks (20 = 1 second) and the sound. Messages are under messages and use MiniMessage colours.

3. First commands

  • /crate list shows every crate.
  • /crate edit vote opens the in-game editor: drag items in, close to save.
  • /crate setchance vote 10 15 sets the chance of the reward in slot 10 of the vote crate.
  • /crate give Steve vote 3 gives Steve 3 vote keys.
  • /crate preview vote shows the rewards and their chances.
  • /crate reload reloads the config after editing the file.

Players right-click a key to open its crate and left-click it to preview.

4. Permissions

  • clearcrates.use: list and preview crates. Everyone has it by default.
  • clearcrates.admin: give, edit, setchance and reload. Ops by default. Give it to staff with /lp user <player> permission set clearcrates.admin true.

Common questions

Do the chances need to add up to 100?

No. They're weights, and the preview shows each reward's real percentage.

What if a player's inventory is full?

The reward drops at their feet, so it's never lost.

Does it need other plugins?

No. PlaceholderAPI (%clearcrates_keys_<crate>%), ItemsAdder and Nexo are optional hooks.
