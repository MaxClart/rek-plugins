ClearSpawners setup guide

Set up stackable virtual spawners with storage, collect and sell all.

Buy ClearSpawners — $9.99 Plugin page

1. Install

Follow the getting started guide: put ClearSpawners-1.0.0.jar in plugins/, restart, and check the console. The config is created at plugins/ClearSpawners/config.yml.

2. Optional: Vault for Sell all

Sell all pays through Vault, so install Vault and an economy plugin such as EssentialsX. Without them, everything else works and the Sell all button is greyed out.

3. Using spawners

  • Place spawners as normal, or give them with /spawners give Steve pig 1 3 (player, mob, amount, stack).
  • Right-click a spawner to open its storage: Collect items, Collect XP or Sell all.
  • Right-click it while holding a spawner of the same type to stack. Sneak-right-click does neither.
  • Break it with a silk touch tool (or with clearspawners.pickup) to keep the spawner and its stack.

4. Config

Edit plugins/ClearSpawners/config.yml (max stack, drop tables, intervals, XP, prices), then run /spawners reload. Data is kept in plugins/ClearSpawners/spawners.yml.

5. Permissions

  • clearspawners.use and clearspawners.sell: everyone by default.
  • clearspawners.pickup and clearspawners.admin: ops by default.

What was tested?

Stacking, storage, Collect items, Collect XP, Sell all (with Vault and EssentialsX), silk touch pickup and restarts were tested with a bot using a pig spawner on Paper 1.21.4. Pickup by permission without silk touch, breaking without silk touch, explosion protection and mobs other than pig were not bot-tested.
